# 🏥 Hospital Management Data Analytics Pipeline

An end-to-end cloud-based data analytics project demonstrating how hospital management data is ingested, processed, stored, and visualized using Microsoft Azure, Snowflake, SQL, and Power BI.

---

## 📌 Project Overview

This project demonstrates the implementation of a modern data analytics pipeline using Azure cloud services and Snowflake.

The pipeline starts with raw hospital management datasets stored in Azure Data Lake Storage Gen2. Azure Data Factory orchestrates the movement of data from cloud storage into Snowflake using automated ETL pipelines. The processed data is then used to build interactive dashboards in Power BI for business reporting and analysis.

This project was developed to gain hands-on experience with cloud-based data analytics technologies and to demonstrate practical implementation of an end-to-end analytics solution.

---

## 🎯 Project Objectives

- Store raw hospital datasets in Azure Data Lake Storage Gen2.
- Build automated ETL pipelines using Azure Data Factory.
- Load data into Snowflake Data Warehouse.
- Perform SQL-based data transformation.
- Build interactive Power BI dashboards.
- Understand modern cloud-based data analytics architecture.
